## 现状

**结论先行：三种敌人打起来一模一样。** 玩家能感知到的差异只有「血多一点 / 走得快一点」。

### 1. 近战伤害三者全为 1（被公式截平）

`demo_latest.html:2688-2689`（敌人生成处）：

```js
meleeDmg:  Math.max(1, 1 + abilityMod(eAbilities.str)),
rangedDmg: Math.max(1, 1 + abilityMod(eAbilities.int)),
```

`abilityMod(score) = Math.floor((score - 10) / 2)`（1129 行）。代入 `ENEMY_STATS`（601-620）：

| 类型 | str | 力调 | `1+力调` | 实际近战伤害 |
|---|---|---|---|---|
| 骷髅 | 10 | 0 | 1 | **1** |
| 幽灵 | 8 | -1 | 0 | **1**（被 `max(1,…)` 兜底） |
| 外星人 | 0 | -5 | -4 | **1**（被 `max(1,…)` 兜底） |

外星人走远程（`int 10` → mod 0 → 伤害 1），所以**连远程也是 1**。
设计上「骷髅是硬汉、外星人是脆皮法师」的属性差异，在输出端**完全不体现**。

### 2. AC 三者全为 9（公式巧合）

`AC = 5 + ⌊(dex + con) / 4⌋`，而三者 dex+con 恰好都等于 16（骷髅 6+10、幽灵 10+6、外星人 8+8）→ **AC 全 9**。

### 3. 类型均匀随机，第 1 关就出远程狙击

`initLevel` 2672 行：`const type = ENEMY_TYPES[randInt(ENEMY_TYPES.length)];`
→ 第 1 关就有 **33% 概率**出现外星人（停下格对同行/列开枪、无视距离）。新手关挨狙，且敌人类型毫无节奏感。

### 4. 实际上仅存的差异

| 维度 | 骷髅 | 幽灵 | 外星人 |
|---|---|---|---|
| HP（L1） | 10 | 6 | 8 |
| 移动 `⌊dex/2⌋` | 3 | 5 | 4 |
| 命中加值（力调+熟练） | +1 | +1 | **-3**（近战几乎打不中，靠远程） |
| 伤害 | 1 | 1 | 1 |

> 附带说明：`rollEnemyAttack(eStrMod, e.prof, pAC)`（4335 行）用的是 **str 修正 + 熟练**，外星人 str 0 → 近战命中 -3，但它几乎不用近战，所以这个负数平时看不到。

## 期望

1. **伤害不再被截平**：力量/智力的差异要真能打出来，玩家挨一下能分辨出"这是骷髅打的还是幽灵打的"。
2. **新增 2–3 种敌人**，每种有明确战术定位（不只是换皮数值）。
3. **类型按关卡解锁 + 权重**：前期不出远程狙击型，新类型分批登场，让关卡有节奏。

### 方案建议（实施时可调整，但必须满足上面的目标）

**A. 伤害公式（推荐「伤害骰」方案，最直观也最贴近 D&D 原型）**
把伤害从「常量」改成「骰子」，按类型给不同的骰：

| 类型 | 建议伤害 | 说明 |
|---|---|---|
| 骷髅（硬汉） | `1d4`（1–4） | 正面硬碰硬，单下最疼 |
| 幽灵（灵敏） | `1d2`（1–2） | 打得快、移动高，但单下轻 |
| 外星人（狙击） | 远程 `1d4`（1–4） | 远距离高伤，近战几乎无威胁 |

若不想引入骰子，退而求其次：`dmg = max(1, BASE[type] + abilityMod(attr))`，`BASE` 骷髅 2 / 幽灵 1 / 外星人 1。
**注意：无论哪种方案，`meleeDmg`/`rangedDmg` 都要保留为「单位实例上的字段」**（2688-2689 现有结构），供日志与 AI 读取。

**B. AC 差异化**
让至少一种敌人的 AC 明显不同于另外两种（改 `dex`/`con` 即可，因为 AC 由二者推导）。
⚠️ 已知约束：改 `dex` 会连带改移动力（`⌊dex/2⌋`），改 `con` 会连带改 HP（`maxHp = con + hpBonus`）。要一并考虑。

**C. 新敌人候选（选 2–3 个）**
- **盾卫**：高 AC / 高 HP / 移动 2 / 伤害低 → 逼玩家绕后或改用远程
- **自爆虫**：HP 极低（3–4）/ 移动 5 / 接触即造成 3–4 点伤害并自毁 → 逼玩家保持距离（注意：涉及"死亡时触发效果"，需确认与击杀奖励、技力获取的关系）
- **增益型（治疗/加护）**：每回合给相邻同伴回 1 HP 或 +1 AC → 逼玩家优先集火

**D. 解锁节奏建议**

| 关卡 | 可用类型 |
|---|---|
| L1–2 | 骷髅 |
| L3+ | + 幽灵 |
| L5+ | + 外星人 |
| L8+ | + 新类型 A |
| L12+ | + 新类型 B |
