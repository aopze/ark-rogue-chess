### 方案：单一外链 SVG，棋盘图标与选角大图共用一份

宝可梦 dream-world 素材是**真矢量**（已验证无内嵌位图），带来一个关键好处：
**同一份 SVG 既能当棋盘 24px 单位图标，又能当选角大图** —— 矢量无损缩放，**不需要像 PNG 那样准备「小图标 + 大立绘」两套资源**。

> 这也意味着原「第二层：外链 WebP 立绘」被**取消**：不再需要 WebP，4 个 SVG 通吃两种尺寸。

- 存放位置：自有服务器 `https://<域名>/assets/char/<内部id>.svg`
  - 例：`assets/char/wheelchair.svg`（风笛）、`vampire.svg`（华法琳）、`fencer.svg`（泥岩）、`amiya.svg`（阿米娅）
  - ⚠️ 文件名用**内部 id**，不要用中文显示名
- 渲染：`<img class="unit-icon" src="…svg" onerror="…">`
- **必须带降级**：加载失败时回退到该角色当前的 emoji，保证离线 / 分享 / 网络异常时仍可玩 —— 这是外链方案唯一的硬伤，必须有兜底
- **不做内嵌**：4 件内联 +132KB、base64 +176KB，会让 261KB 的单文件膨胀 50%+

**技术约束：着色改用 CSS filter**

这些是**彩色复杂立绘**（多个 path 各自带 fill），不是单色图标：
- ❌ 不能用 `fill="currentColor"` 统一变色 —— 会毁掉原图配色
- ✅ 改用 **CSS filter**，且 **外链 `<img>` 同样生效**（filter 作用于元素本身，不需要访问 SVG 内部）：
  - 眩晕 / 失能 → `filter: grayscale(1) opacity(.7)`
  - 受伤闪红 → `filter: brightness(1.4) sepia(1) saturate(5) hue-rotate(-30deg)`
  - 敌方阵营 → `filter: hue-rotate(180deg)` 或 `drop-shadow(0 0 4px #f66)`

> 因此**原「内嵌 SVG symbol + currentColor」那层方案对本套素材不适用**，已整体取消。
> 副作用：角色走 `<img>` + filter，敌人走 emoji 文本 —— 棋盘渲染需要**分支处理两种图标类型**，见「涉及区域」。
