# 风笛「高效冲击」改为：冲锋段几格就打几次（多次连锁攻击）

- **提出人 / 时间**：人类维护者 / 2026-10-28 01:20
- **类型**：balance（角色核心技能机制改动）
- **优先级**：P1 明显影响体验
- **状态**：ready

## 现状

风笛（`wheelchair`）技力满 5 后，双击路径节点设技能节点 → 到达该步发动「高效冲击」：

1. **冲锋段**：`computeStraightChargePath()` 从触发点沿朝向一直延伸到撞墙/出界，得到 `chargePath`（长度 N）。原规划路径剩余部分被**整段替换**，所以「剩下路径」= 这一段。
2. **冲锋期间**（`playerChargingThisTurn`）：
   - 免疫一切伤害（`IMMUNE_CHARGE`）
   - 撞到敌人 → 造成 `meleeDmg × 2` 的「冲锋撞击」**一次**
   - 敌人**没死就停下**（`playerBlocked = true`），冲锋结束
   - 敌人死了则穿过继续冲
   - 攻击节点被禁用：`attackIndices = attackIndices.filter(idx => idx < chargeIdx)`
   - 全程未造成伤害却撞墙 → 失去一半 HP

**问题**：冲锋段有 N 格，但实际最多只打「一次撞击」。撞上第一个没秒掉的敌人就停，N 格的意义只剩位移，
与「沿直线高速冲锋撞穿敌阵」的直觉不符。

## 期望

**核心：冲锋段格数 N = 本回合攻击次数 N，每次伤害为 `meleeDmg × 2`（朝向伤害口径）。**

1. **攻击次数**：取冲锋段格数 N（`chargePath.length`），进入冲锋状态时即锁定该额度。
2. **每次伤害**：`meleeDmg × 2`，与现有「冲锋撞击」一致（即朝向伤害 ×2 的口径，见 `isFacingTarget` 的 `ed *= 2`）。
3. **正常推进**：每前进 1 格消耗 1 次攻击额度，攻击目标为**朝向方向上**的敌人（严格按 `isFacingTarget` 判定，不打侧面与背后）。
4. **被敌人挡住时**：仍按现有语义**立即停下**（不再前进），但**剩余攻击次数不作废** ——
   改为对**朝向前方 3 格范围内的敌人**继续逐次输出，直到 N 次额度用完。
   - 目标挑选：优先距离最近的存活敌人（通常就是挡住你的那个）；打死后再顺延到范围内下一个。
   - 范围内没有敌人则该次落空，不累积。
5. **保持不变**：
   - 冲锋期间免疫一切伤害
   - 冲锋段仍整段替换原规划路径；冲锋后的路径节点/攻击节点仍被丢弃
   - 全程未造成伤害又撞墙 → 失去一半 HP（撞墙判定在「停下后继续攻击」之后结算，若期间打中过敌人则免伤）
   - 占一次动作（技能节点）
6. **文案同步**：风笛 `tips` 里 `[高效冲击]` 那条、`prepareWheelchairCharge()` 的日志、可能的仪表盘动作提示，都要改成新口径。

## 验收标准

- [ ] 冲锋段 5 格、路径全空 → 5 次攻击全部落空，位移到墙前，无报错
- [ ] 冲锋段 5 格、第 2 格有敌人（HP 够抗 1 下不死）→ 第 2 格打 1 次后**停下**，剩余 4 次继续打该敌人（或其朝向 3 格内的其他敌人），总计 5 次伤害
- [ ] 上述场景把敌人 HP 调到 1 下就死 → 打死并穿过继续冲，后续格数照常攻击

- [ ] 冲锋期间玩家不吃任何伤害（外星人狙击 / 近战 / 相杀均免疫）
- [ ] 全程未造成伤害且撞墙 → 掉一半 HP；期间造成过伤害 → 撞墙免伤
- [ ] 日志能看出「本次冲锋额度 N 次，已命中 M 次」

## 备注

- **平衡风险（重要）**：N 格 × 2 倍近战伤害，若冲锋段 6 格就是 12 倍近战输出，属于大幅增强。
  若实测过强，备选收敛方案（任选，需人类维护者拍板）：
  ① 只对「撞击首个敌人」保留 ×2，后续补充攻击降为 ×1；
  ② 攻击额度上限封顶（如最多 4 次）；
  ③ 停下后补充攻击的射程由 3 格收紧为 1 格。
- 「朝向 3 格」按**朝向直线方向 3 格**理解（`facing × k, k=1..3`）。
  若希望改成「`isFacingTarget` 为真且 `dist ≤ 3` 的所有敌人群体命中」，请说明，实现口径不同。
- 与 issue 的联动：若未来加入「冲锋撞墙不掉血」的遗物/增益，需在此处预留判定点。
