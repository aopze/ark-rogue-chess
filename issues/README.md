# issues/ · 需求入口

**想改游戏？往这个目录写文件，不要直接改 `game.html`。** 规则全文见 [README §0.0](../README.md#00-铁律不直接改游戏先写-issue-文件)。

## 三步

1. 复制模板并改名：
   ```bash
   cp issues/_template.md issues/ISSUE-20261028-01-你的短标签.md
   ```
   命名格式：`ISSUE-<YYYYMMDD>-<两位序号>-<英文小写连字符标签>.md`

2. 填完模板（**验收标准必填**，否则不算 `ready`）。

3. 提交推送。之后等人类维护者说「版本更新」，才会有人按这里的条目动手改游戏。

## 谁在读

- **人类维护者**：审需求，决定做不做、什么时候做。
- **实施方（AI 协作代理）**：只在「版本更新」指令下达时批量读取并实施。

## 状态

`draft` 想法不完整 → `ready` 信息够开工 → `implementing` 本轮在做 → `done` 已上线（**随即删除文件**）

已完成的 issue 不要留在目录里，历史在 git 提交记录中。

## 唯一例外

线上完全不可玩（白屏 / 无法选角 / 无法结算）时可先修再补 issue，但需在提交信息里写明
「紧急修复，对应补 issue：`<文件名>`」，并当天补上。
